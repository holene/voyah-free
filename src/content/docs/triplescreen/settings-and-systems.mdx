# System Settings

From the **Settings app** on the control screen, you can adjust:

- **Display brightness** and themes  
- **Date, time, and language**  
- **Sound system configuration (Dynaudio)**  
- **Network connections (Wi-Fi, Bluetooth, Hotspot)**  
- **Privacy and factory reset options**

### Dynaudio Sound System
Adjust `Balance`, `Fader`, `Bass`, and `EQ` profiles.  
System supports speed-compensated volume and sound field focus.

### Privacy Options
Enable privacy mode to hide contact and media data during incoming calls.
