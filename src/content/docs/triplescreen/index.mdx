# Trippelskjermen (Triple Screen System)

The **Voyah Free Trippelskjerm** integrates three connected displays:

1. **Driver screen** — vehicle data and driving info  
2. **Control screen** — system settings and main interface  
3. **Passenger screen** — entertainment and co-pilot functions

Main software version covered: **v20.1 (April 2025)**.
